# CPAN-212-LAB5
Netflix Data Analytics Project – CPAN 212 Lab 5

For Lab 5, I chose to explore data analytics using Python and the Netflix Titles dataset from Kaggle. I used libraries like Pandas, Matplotlib, and Seaborn to clean and analyze data about TV shows and movies on Netflix.

Some of the insights I gathered include:
- There are more movies than TV shows.
- The United States produces the most content.
- TV-MA is the most common rating.
- Movie durations typically range between 80 to 120 minutes.

This project helped me understand how to load and clean real-world data, visualize trends, and interpret findings. It was similar to the course in terms of working with data structures and JSON-like data, but it introduced me to new tools in Python for analytics.

I found this project very useful and would like to explore more in this direction.
